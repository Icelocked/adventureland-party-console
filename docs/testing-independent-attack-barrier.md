# Independent approach attack barrier inventory

Before amending the independent architecture, the user's clarified contract requires every fighter's real native range and sightline to the exact selected monster before any new-target attack. Independent routing remains per actor; arrival does not authorize a pull. The existing coordinator can commit a planned target after acknowledgements alone, including cached queue preack. This is the pre-code failing boundary.

Risks: a first ready actor attacking while peers route; preack bypassing readiness; stale or wrong selection/target reports authorizing a new pull; false capability/legacy reports; confusing physical healing cohesion with range/LOS; and interrupting existing pending/engaged defense. The optional independentReady report is a client-read native conjunction of range and sightline, exact raw target ID/current selection and server-adjusted at time. All current participants must be fresh and ready for a planned commit, independently of ACK/preack. Early arrivals hold position in the client. Existing engaged/pending fights retain normal ownership; no healer group route is restored. Native E2E must prove no actual outgoing attack before every actual range/LOS arrival.
