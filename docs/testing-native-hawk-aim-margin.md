Before this amendment, the native Hawk declaration searched range-minus-three rings. The operator now requires the approach aim to begin ten units inside actual attack range. Leaving the declaration at three would test different geometry from the maintained controller.

Both initial and half-radius native geometry probes now derive from range minus ten. The first actual owned caster move must report a radius equal to max(1, (actual staged native range - 10) / 2**issued level), with matching issued route identity. This checks the emitted approach rather than a source string. Actual native attack-range readiness, fresh all-party confirmation, real damage, and the absolute thirty-second deadline remain unchanged.

This patch is separate from the proposed safe roaming successor input amendment. No native run is performed while the parent's existing batch is active.
