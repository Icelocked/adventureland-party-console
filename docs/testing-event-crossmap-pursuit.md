# Cross-map event pursuit

Before editing production, native run 38282332581 shard 10 artifact 11765487364
shows Warrior's Green reentry route rebuilt six times and Pumpkin rebuilt nine
times. The same live boss moves every twenty seconds; a fresh Priest sighting
restarts the entire owned route while Warrior is still on Main, level1, or
level2. Repeated preparation/departure consumes most of each interval.

Failure modes: cross-map progress repeatedly cancelled for destination-only
coordinate changes; local pursuit never catches the moved boss; stale, different
boss, foreign-instance or superseded observations accepted. A retained regression
first verifies the exact owned route remains intact outside the destination
map/instance and the latest fresh position is accepted after arrival. Existing
native reentry deadlines and real post-respawn damage proofs remain unchanged.
